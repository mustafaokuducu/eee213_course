# Data

**ccpp.csv**: Combined Cycle Power Plant dataset.
- Source: P. Tüfekci and H. Kaya, "Combined Cycle Power Plant," UCI Machine Learning Repository, 2014, doi:10.24432/C5002N.
- Licence: CC BY 4.0. Converted from XLSX to CSV (file provided on the EEE213 Week 09 lesson page).
- 9,568 rows × 5 columns: AT (°C), V (cm Hg), AP (mbar), RH (%), PE (MW). One row = one hourly average, full load, 2006–2011.
- Target: PE (net electrical output, MW).
